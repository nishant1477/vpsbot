How provisioning works

The web panel is read-only for safety: instances are provisioned through the Discord !create wizard so that node scheduling, capacity checks and credentials delivery all happen in one auditable place.

  • The scheduler picks the least-loaded online node that fits your plan.
  • Root passwords are encrypted at rest and shown once.
  • Status updates stream back via the node agent heartbeat.
